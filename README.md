# Employee Records Management System

## Project Overview

The Employee Records Management System is a Django-based web application designed to provide a simple interface for managing and viewing employee information. The project was developed as part of the Omegtric Full-Stack Web Development programme.

## Module 2 — Developer Tools and Git Collaboration

During Module 2, the application was inspected and improved using browser Developer Tools. The Elements, Console, and Network panels were used to investigate the frontend and verify application behaviour.

A small frontend improvement was implemented by adding an interactive **Show System Information** button to the home page. The button uses JavaScript to display and hide additional system information without requiring a page reload.

The project was developed using a Git feature branch named `dev-tools`, committed, pushed to GitHub, and submitted through a Pull Request for review.

## Open-Source Component Evaluation

### Component Name

**Bootstrap 5**

### Purpose

Bootstrap is an open-source frontend framework that provides reusable CSS classes and interface components for creating responsive and consistent web pages. It provides features such as responsive layouts, navigation elements, buttons, forms, cards, tables, and other user-interface components.

### Potential Use

Bootstrap can help improve the Employee Records Management System by providing responsive layouts and consistent styling for employee lists, forms, navigation, buttons, alerts, and other interface elements.

The project already uses Bootstrap through its CDN stylesheet, making it a suitable component for the current application.

### Decision

**Continue using Bootstrap and consider expanding its use later.**

Bootstrap is appropriate for this project because it can improve the application's responsiveness and user interface while reducing the amount of custom CSS that needs to be written and maintained.
